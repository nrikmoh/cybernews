My Story

Hi! I'm Hassan. I'm a grandpa who decided to dive into the world of cybersecurity and web development. This website is the result of a two-week intensive learning journey.

CyberNews was built entirely from scratch — no templates, no website builders. Every line of HTML, CSS, JavaScript, and Python was written by hand as part of my learning process.

  • JavaScript — Search, filters, animations, real-time interactions
  • Python & Flask — Backend routes, template engine, API endpoints
  • SQLite & SQLAlchemy — Database design, queries, data persistence
  • Security — Password hashing, CSRF, rate limiting, audit logs
  • Deployment — Nginx, Gunicorn, Linux server administration
