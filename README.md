# 🛡️ CyberNews — Cybersecurity Intelligence Daily

A professional cybersecurity news aggregator built from scratch as a learning project.

## Features

- Real-time news from 5 RSS sources (auto-updates hourly)
- 148+ articles across 6 categories
- Smart search with dedicated results page
- Admin panel for content management
- Analytics dashboard with visitor insights
- Newsletter subscription system
- Dark/light mode toggle
- Mobile responsive design
- Security hardened (CSRF, brute force, rate limiting)

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Backend: Python 3.12, Flask
- Database: SQLite + SQLAlchemy
- Auth: Flask-Login + bcrypt
- Security: Flask-WTF, Flask-Limiter
- Server: Nginx + Gunicorn
- OS: Ubuntu VPS

## Security Features

- bcrypt password hashing
- CSRF protection on all forms
- Brute force login protection
- Rate limiting
- Security HTTP headers
- Attack path blocking
- SQL injection prevention
- Login audit logging
